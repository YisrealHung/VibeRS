# VibeRS

**VibeRS** 是一款基於 Rust 與 `egui` 開發的超輕量原生 AI 輔助程式編輯器（Vibe Coding IDE）。  
設計靈感借鑒自 Google Antigravity IDE，具備極致的效能表現、極低的記憶體佔用與強大的本機 AI 串流對接能力。

---

## 🚀 核心指標

- **超小二進位體積**：Release 執行檔僅約 **2.86 MB**（無需 Electron 或龐大的 Web 執行環境）。
- **極低記憶體佔用**：實體工作集 RAM 僅約 **8 ~ 10 MB**（相較於傳統編輯器動輒數百 MB 至 GB 級別，大幅節省系統資源）。
- **即時秒開體驗**：本機原生啟動速度低於 100 毫秒，流暢順暢。

---

## ✨ 主要功能特點

### 1. 🤖 Antigravity 風格 AI 輔助工作區
- **原生對接本機 CLI**：自動偵測並對接本機安裝的 **Gemini (Antigravity CLI)** 與 **Claude Code CLI**。
- **背景非阻塞串流**：採用多執行緒與 `mpsc` 通道，AI 回覆逐字串流輸出，隨時可按 `Stop ⏹` 中斷行程。
- **對話氣泡排版**：採用 Antigravity 對話框視覺設計，使用者提問文字靠右氣泡包裹、自動適配寬度；AI 回覆靠左呈現並支援即時 Markdown 渲染。
- **模型配額與用量統計**：模型選擇清單即時顯示剩餘配額（如 `50/50`、`150/150`、`Unlimited`），底欄按鈕即時標註使用率。
- **專案環境感知**：發送 Prompt 時自動附加當前開啟專案的上下文指引與關聯檔案（支援 `@檔案` 標註）。

### 2. 📝 高效能程式碼編輯器
- **多分頁管理**：支援多檔案分頁切換、儲存提示符號（`*`）、未儲存關閉確認。
- **多語言語法高亮**：內建 Rust、Python、JavaScript、TypeScript、C/C++、Java、C#、Go、HTML、SQL、JSON、Markdown、TOML 等程式語言的高速語法著色。
- **虛擬滾動技術**：編輯區採用動態虛擬渲染，面對萬行大型程式碼仍能維持 60 FPS 順暢滾動。
- **Windows IME 優化**：完美支援微軟繁體/簡體中文輸入法選字流程，解決候選字 Enter 確認誤觸換行的問題。

### 3. 📂 檔案與專案管理
- **樹狀檔案瀏覽器**：乾淨啟動（預設不預載歷史目錄），支援資料夾展開/收合。
- **檔案操作管理**：支援於側邊欄即時新增檔案、新增資料夾、重新命名與刪除。
- **多視窗支援**：支援「開啟新視窗」與「在新視窗開啟指定專案資料夾」。
- **快速檔案切換**：快捷鍵 `Ctrl + P` 呼叫檔案模糊搜尋彈窗。

### 4. 🔍 外部檔案變更偵測與 Diff 檢視
- **磁碟即時監聽**：當專案中的檔案在外部被修改時，自動偵測並在分頁載入變更。
- **內建 Hunk 差異對比**：提供類似 Git 的直觀差異比對介面，支援單一程式碼區塊（Hunk）的「接受（Accept）」或「還原（Revert）」。

### 5. 🎨 雙色主題與字型備援
- **Dark / Light 主題切換**：可透過選單 `File -> 頁面主題 (Theme)` 自由切換深色（Dark）或淺色（Light）模式。
- **淺色專屬調色**：淺色模式下關鍵字、行內程式碼與重點強調自動切換為閱讀舒適的咖啡棕色調。
- **完整的 CJK 字型覆蓋**：自動載入系統微軟正黑體、微軟雅黑、Noto Sans TC 與 Segoe UI Emoji，無任何缺字方框（Tofu glyph）。

### 6. 📊 系統效能即時監控
- 狀態列右下角即時顯示當前實體 RAM 工作集佔用（例如 `RAM: 8.5 MB`）、游標行列資訊與檔案編碼。

## 🛠 系統需求與環境建置

### 需求
- **作業系統**：Windows 10 / Windows 11 (x64)
- **建置工具**：Rust 1.75+ 及 Cargo
- **AI 功能支援（選配）**：
  - [Google Antigravity CLI](https://antigravity.google/)（`agy`）
  - 或 [Anthropic Claude Code CLI](https://docs.anthropic.com/)（`claude`）

### 編譯方式

以極限效能與最小體積建置 Release 版本：

```powershell
cargo build --release
```

編譯產物將生成於 `target/release/vibers.exe`，大小僅約 2.86 MB。

## ⌨️ 常用快捷鍵

| 快捷鍵 | 動作 |
|---|---|
| `Ctrl + O` | 開啟專案資料夾 |
| `Ctrl + P` | 快速開啟檔案（Quick Open） |
| `Ctrl + N` | 新增檔案 |
| `Ctrl + S` | 儲存當前檔案 |
| `Ctrl + W` | 關閉當前分頁 |
| `Ctrl + Enter` | 發送 AI 對話指令 |
